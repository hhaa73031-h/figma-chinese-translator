1. 画框 (Frame) vs 编组 (Group)

在 Figma 中，画框是容器之王！自带独立背景色、圆角、约束和自动布局；而编组只是拿绳子把几样东西捆在一起。界面设计永远优先用画框 (Frame)！

快捷键：按 F 选画框预设，或选中元素按 Ctrl+Alt+G 直接包裹进画框。

2. 自动布局 (Auto Layout) 三剑客

前端 Flex 布局的孪生兄弟！让按钮文字变多时背景自动被撑长。容器排版三兄弟怎么选：

• 固定尺寸 (Fixed)：固定写死尺寸（如头像 40×40）。
• 适应内容 (Hug)：根据里面的字或内容自动包裹。
• 填满容器 (Fill)：自动撑满父级画框的全部剩余空间！

快捷键：选中元素按 Shift + A 立即启用自动布局！

3. 组件 (Component) 与实例 (Instance)

组件是“印章母版”，实例是用它盖出来的“印记子副本”。修改母版的颜色或圆角，成千上百个页面上的副本会自动同步改变！但各个副本可以单独修改里面的文字与配图。

快捷键：选中做好的按钮按 Ctrl + Alt + K 快速创建主组件母版。

4. 响应式约束 (Constraints) 与蒙版

定义外层画框被拉大拉伸时，里面的元素怎么走。比如把右上角关闭按钮设为“靠右+靠顶”，不管手机屏幕怎么变，它永远稳稳钉在右上角！蒙版 (Mask) 则像遮罩窗户，只透出下面的图层。

快捷键：选中底层形状按 Ctrl + Alt + M 将其设为上层图片的遮罩蒙版。
