# Figma 动态实时汉化管理器 (本地网页版)

> **极简 · 高效 · 随用随译 · 原生无损还原**  
> 专为 Windows 桌面版 Figma 设计的高性能实时汉化与还原工具。采用本地轻量 Web 服务形式运行，开箱即用，免去繁琐安装与频繁升级。

---

## 🛠️ 本次核心问题修复详情（窗口无法唤醒）

针对用户反馈的 **“汉化后 Figma 窗口无法正常唤醒”** 问题，经底层 V8 / Node.js 执行流跟踪与堆栈溯源分析：

1. **反篡改延迟自毁中和（关键突破）**：
   - **深层原因**：Figma 官方在 `bindings.node` 原生 C++/Rust 二进制模块中内置了代码防篡改校验。当检测到 `app.asar` 被重构或签名变动时，底层会悄然注册一个微秒级自毁定时器 `delayedExit`（执行 `() => process.exit(0)`）。
   - **症状表现**：进程以退出码 `0` 瞬间退出，无崩溃日志、无报错弹窗，导致再次点击快捷方式时由于单例锁互斥与静默退出使得窗口无法唤醒。
   - **修复方案**：在注入核心最顶层实现了针对自毁定时器的精准防御拦截，安全中和了非法自毁逻辑，使 Figma 正常完成窗口创建并稳定运行。

2. **渲染进程通信隔离与精准过滤**：
   - 严格隔离了桌面原生窗口外壳（`shell.html`，运行 React 框架）与加载动画（`loading_screen.html`），汉化脚本仅注入至 `figma.com` 设计工作区页面，彻底避免 React 挂载阶段的冲突与白屏。

## ✨ 核心特性

- ⚡ **一键开启动态实时汉化**：
  - 基于高精度 DOM `MutationObserver` 与智能正则表达式，新打开的画布、弹窗、工具栏自动汉化。
  - 新功能发布无需频繁更新汉化器。
- ⟲ **一键还原官方英文**：
  - 自动创建并保留原版 `app.asar.bak`。
  - 一键 100% 无损恢复官方最新原版文件，登录态与个人偏好完全保留。
- 🎨 **专属视觉定制**：
  - **严格零蓝紫配色**：采用黑曜石碳黑（`#0c0e12`）与工业琥珀金（`#d97706`）、翡翠绿（`#10b981`）搭配。
  - **严格 0~2px 硬朗微圆角**：摒弃大圆角与气泡卡片，呈现专业极简设计工具质感。
- 🖥️ **本地网页版控制台**：
  - 零外部三方依赖，标准 Python 原生启动。
  - 自动调起系统默认浏览器，提供直观的按钮与终端实时动态日志输出。

## 🚀 启动与使用方式

### 方式一：双击批处理脚本（推荐）
在项目根目录下双击：
- `启动本地网页汉化器.bat`（或 `start_web_gui.bat`）

脚本将自动启动后台服务并在默认浏览器中调起控制面板。

### 方式二：命令行启动
在当前目录下打开终端，执行：
```bash
python web_server.py
```
终端将输出：
```
============================================================
  Figma 实时动态汉化管理器 (本地网页版)
  服务已启动: http://127.0.0.1:8765
  在浏览器中打开上方网址即可控制汉化与还原
============================================================
```
浏览器访问 `http://127.0.0.1:8765` 即可使用。

## 📋 功能操作指南

1. **开启实时汉化**：
   - 点击面板中的 **【 ⚡ 一键开启实时汉化 】** 按钮。
   - 系统将自动安全结束后台 Figma 进程、创建原版备份并注入汉化引擎与反篡改防护。
   - 汉化完成后点击 **【 🚀 启动 Figma 】** 即可体验流畅的中文界面。
2. **还原官方英文**：
   - 点击面板中的 **【 ⟲ 一键还原官方英文 】** 按钮。
   - 系统将自动恢复官方原生 `app.asar` 文件，立即还原官方英文环境。
3. **辅助控制**：
   - **【 🚀 启动 Figma 】**：无需寻找桌面图标，直接快速唤醒并启动 Figma。
   - **【 ⏹ 结束 Figma 进程 】**：快速清理所有驻留的 Figma 后台进程。
   - **【 🔄 刷新状态 】**：即时检测当前环境与进程状态。
